O que a gente mede neste site.

Este site usa o Google Analytics para contar visitas: quantas pessoas entram, de onde vêm, quais páginas abrem e se clicam no botão de conversar. É o que a gente precisa para saber se o site está cumprindo o papel dele.

Os números são agregados. A gente vê que trinta pessoas vieram do Google esta semana, não quem são. Nenhum dado é usado para anúncios, para montar perfil de quem visita ou cruzado com outras bases. O Google recebe esses dados como nosso fornecedor de medição e os guarda por 14 meses.

Para reconhecer que duas visitas são da mesma pessoa, o Google Analytics grava um pequeno arquivo no seu navegador, o cookie. Ele não contém nome, e-mail nem telefone. Você pode apagá-lo a qualquer momento nas configurações do navegador.

Se preferir não ser contado, é só usar o botão abaixo. A escolha fica salva neste navegador e vale para todas as páginas do site.

Quando você fala com a gente

Os botões de conversar abrem o WhatsApp. O que você escrever ali fica entre você e a FORSTER, e a gente usa só para responder e, se virar trabalho, para fazer o trabalho. Nada vai para lista de e-mail nem para terceiros.

Qualquer dúvida sobre os seus dados, é só escrever para o Samuel pelo WhatsApp ou pelo Instagram. Responsável: FORSTER Ateliê de Conteúdo, Igrejinha, RS.
